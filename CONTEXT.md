# CUNY Plus

CUNY Plus helps students identify the RateMyProfessors profile associated with an instructor on a CUNY course listing and provides opt-in automatic submission of saved CUNY Login credentials.

## Language

**Brightspace**:
CUNY's learning management system for course materials and activities.
_Avoid_: Blackboard

**Student Center**:
The student self-service area within CUNYfirst for enrollment, records, and finances. It is distinct from the CUNYfirst home page.
_Avoid_: CUNYfirst home

**CUNYfirst pages**:
The CUNY Login, CUNYfirst home, Student Center, Schedule Builder, and other first-party pages in the CUNYfirst workflow.
_Avoid_: All CUNY websites

**DegreeWorks**:
CUNY's degree audit system for reviewing academic requirements and progress toward graduation.
_Avoid_: Degree Work

**Selected-course list**:
The courses and class-selection criteria chosen on the left side of CUNY Schedule Builder as inputs for generating schedule options. It is distinct from the displayed schedule.
_Avoid_: Available classes, displayed schedule, registered schedule

**Displayed schedule**:
The one generated schedule option currently shown in CUNY Schedule Builder for the selected term. It is a planning result, not evidence of enrollment.
_Avoid_: Registered schedule (before enrollment)

**Schedule entry**:
One independent class entry in a displayed schedule. It may contain multiple meeting times, such as a lecture and a lab; entries with the same course code remain distinct.
_Avoid_: Course (when distinguishing class entries), meeting time

**Course instructor**:
The person named as an instructor on a course listing. The listing's name is evidence of identity, not proof that a particular RateMyProfessors profile belongs to that person.
_Avoid_: Matched professor (before identification)

**Course campus**:
The CUNY institution associated with the instructor's course listing. It is distinct from the school recorded on a candidate profile.
_Avoid_: Profile school (for the course campus)

**Professor candidate**:
A RateMyProfessors profile returned as a possible match for a course instructor, identified by its professor name, profile school, and profile link.
_Avoid_: Match (before identification)

**Automatic match**:
A professor candidate whose name and profile school unambiguously correspond to the course instructor and course campus.
_Avoid_: First result, best guess

**User-selected candidate**:
A professor candidate explicitly chosen by the student when the available identity evidence does not establish an automatic match.
_Avoid_: Automatic match, verified identity

**Professor rating**:
The rating information attached to a specific RateMyProfessors profile. Its attribution is to that profile's professor name and school.
_Avoid_: Course rating

**Login settings revision**:
A non-secret random identifier generated by an explicit settings save. Re-saving credentials requests one new automatic login attempt in each open CUNY SSO tab.
_Avoid_: Credential hash, password version

**Automatic login attempt**:
One submission using a saved login settings revision. The SSO tab records the revision before clicking Submit so an unsuccessful redirect cannot create a retry loop. It does not establish whether authentication succeeded.
_Avoid_: Successful login, browser-wide session
