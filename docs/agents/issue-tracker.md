# Issue tracker

Issues for CUNY Plus live in [GitHub Issues](https://github.com/StevenHuangYH/CUNY-Plus/issues) for `StevenHuangYH/CUNY-Plus`.

Use the connected GitHub tools for reads. For writes, use an authenticated GitHub surface with issue-write access, such as the browser UI or an authenticated `gh` CLI.

Publish dependent tickets in blocker-first order. Add GitHub's native **Mark as blocked by** relationship and list each direct blocker as `Blocked by: #<number>` in the dependent issue's body. Apply the `ready-for-agent` label to specified tickets. Leave any source issue open and unchanged.

**PRs as a triage surface:** no.
