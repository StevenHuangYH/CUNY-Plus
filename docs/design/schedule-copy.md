# 当前课表一键复制：设计访谈记录

状态：用户已于 2026-10-19 确认整体设计。已根据 2026-10-20 登录后的真实 Schedule Builder 结果页面核对方案边界与字段来源，并完成页面适配及对应 DOM 测试。仍需在更新后的扩展载入 Chrome 后进行实际按钮操作验证。

## 目标与范围

- 目标产品是 CUNY Plus Chrome 扩展。个人网站只展示该项目链接，不承载本功能。
- “当前课表”是 CUNY Schedule Builder 此刻展示的**一套生成方案**，不是所有备选方案、左侧课程选择清单，也不等于已正式注册的课程。
- 在课表结果区域提供两个并排操作：“Copy text”和“Copy table”。各按钮点击一次便复制对应格式；表格格式面向粘贴到表格软件。
- 用户切换方案后，再点击复制应读取当时显示的方案，避免复制先前方案。

## 已确认的复制内容

- 按当前方案中的每个课表条目分别复制：课程代号、课程名称、当前方案在 Schedule Builder 中显示的授课教师姓名、上课时间、教授评分。不附加班次、校区、授课方式或地点等其他字段。
- 一门课有多个上课时段时列出全部时段：文字格式逐行列出，表格格式每门课一行，全部时段放在同一个时间单元格。异步部分写“No fixed time”；若同时存在固定时段和异步部分，两者都列出。页面没有提供时间时写“Not provided”，不推测。
- 当前方案中的每个独立课表条目分别复制；即使课程代号相同，也不合并两个条目。一个条目的讲课、实验课等多个时段仍属于同一行。
- 教授姓名以当前方案中显示的教师为准，不用 RateMyProfessors 档案姓名替换。当前班次同时显示多名教师时，列出全部显示姓名。页面只显示 `Staff`、`TBA` 等占位文字时保留原文，评分标为“Instructor TBA”。仅当评分与每位显示教师的归属能可靠确认时，才分别对应评分或状态；无法确认归属时保留页面显示的姓名，并将评分标为“Identity unclear”，不将一人的评分赋给所有人。
- 有可用教授评分时只写分数，不附档案姓名、链接或其他评分指标。评分必须属于现有评分功能已自动匹配或用户已选定的档案；复制动作不主动发起评分查询。区分“Not searched”“Needs confirmation”“No result”“Search failed”以及已确认档案没有分数时的“N/A”；不把缺失或未确认当作 0 分。
- 点击复制时若已有评分查询尚未完成，立即复制并将该评分标为“Searching”；稍后再次复制才反映查询结果，不让一次复制操作等待查询完成。
- 切换方案后，不仅凭相同的教师姓名和校区就复用另一课表条目的查询结果或用户选择。只有能可靠确认仍是同一课表条目、且教师信息未变时，才保留其评分状态；否则按当前条目的状态输出。
- 某些字段无法读取时，仍复制可读到的课程与字段，并明确标注缺失；不悄悄跳过课程，也不生成看似完整的错误信息。
- 若无法可靠识别当前显示的完整方案，则禁用复制并说明原因；该情况不同于已识别方案中的个别字段缺失。
- 若能识别当前方案但其中没有课表条目，禁用两个复制按钮并说明没有可复制的课程。
- 若页面可可靠读取学期或方案序号，将读得到的信息放在文字格式顶部；只读到其中一项时也显示该项，不推测另一项。表格格式只包含表头及课程数据行，便于粘贴到表格软件。
- 表格格式采用制表符分隔列，每个课表条目占一行。单元格内的多位教师、多项评分或多个时段用“；”分隔；能够分别确认归属时，教师与评分按相同顺序对应；归属不清时使用单个“Identity unclear”状态。单元格内不换行。
- 新按钮、复制内容中的字段名、缺失标记和评分状态标签均使用英文，与扩展现有界面一致；本文档继续用中文记录产品规则。

## 实现与验证

- `src/contents/content-schedule-copy.ts` 在 Schedule Builder 中运行；`read-schedule.ts` 从当前可见的 `#flip_area #legend_box` 读取完整方案，每个直接子级 `.course_box` 作为独立条目，并读取课程标题、名称、时间、教师与学期。结果序号从 `.results-with-schedules` 读取。
- `src/features/ratings/useProfessorLookup.ts` 将现有评分查询及用户选择记录到对应教师元素；复制时只读取快照，不额外查询。方案变化会使快照失效。
- 本地模拟页和真实页面结构的 DOM 样本都有自动化测试。真实浏览器当时展示一套含两个条目的方案，页面字段与上述选择器吻合；更新后的扩展尚未载入该浏览器，所以仍需一次实际复制操作验证。
- 评分身份规则见 [`professor-rating-matching.md`](./professor-rating-matching.md) 和根目录 `CONTEXT.md`。
