When reading, creating, or triaging tickets, use GitHub Issues. See [issue-tracker.md](docs/agents/issue-tracker.md).

### Triage labels

When applying a triage role, use the repository's label mapping in [triage-labels.md](docs/agents/triage-labels.md).

### Domain docs

Before naming domain concepts in plans, tickets, or code, read [domain.md](docs/agents/domain.md).
